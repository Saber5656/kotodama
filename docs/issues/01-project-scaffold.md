# Title

Project scaffold: XcodeGen app skeleton, KotodamaKit package, lint config

## Summary

Create the buildable skeleton of the kotodama macOS app: XcodeGen `project.yml`, a menu-bar-only SwiftUI app target, the `Packages/KotodamaKit` SwiftPM package with empty module targets, lint/format configs, and `.gitignore`. No product features.

## Context

kotodama is a resident, menu-bar-only dictation app (DESIGN §1, §5). ADR-001 fixes the stack: Swift 6 strict concurrency, SwiftUI, macOS 14.0+, arm64 only, XcodeGen-generated project, modular SwiftPM core. Everything later builds on this layout, so paths and target names below are binding.

## Scope

- `project.yml` (XcodeGen) defining app target `Kotodama`.
- `App/` sources: `@main` SwiftUI app with `MenuBarExtra` showing a placeholder icon and menu (About, Quit).
- `Packages/KotodamaKit/Package.swift` with **empty but compiling** library targets: `CoreTypes`, `SettingsStore`, `Diagnostics`, `PermissionsService`, `AudioCapture`, `HotkeyService`, `ModelCatalog`, `ASRService`, `FormattingService`, `InsertionService`, `HistoryStore`, `DictationController`, plus mirrored empty test targets.
- `.swiftlint.yml`, `.swiftformat`, `.gitignore`, `Frameworks/.gitkeep`, `scripts/.gitkeep`.
- Build documentation section in a new `docs/BUILD.md`.

## Detailed Requirements

1. `project.yml`:
   - App target `Kotodama`, bundle id `io.github.saber5656.Kotodama` (placeholder per DESIGN §21 U2 — define once in a yml variable), deployment target macOS 14.0, `ARCHS=arm64`, Swift 6 language mode, strict concurrency `complete`.
   - `Info.plist` generated by XcodeGen with: `LSUIElement=true`, `NSMicrophoneUsageDescription` (JA text: "音声入力のためにマイクを使用します。音声は端末外へ送信されません。" + EN equivalent via InfoPlist string catalog), CFBundleShortVersionString `0.1.0`, build number `1`.
   - Entitlements file `App/Kotodama.entitlements`: Hardened Runtime on (via `ENABLE_HARDENED_RUNTIME=YES` build setting), **App Sandbox absent/false** (ADR-006), no other entitlements.
   - App target depends on the `KotodamaKit` local package products it needs (initially `CoreTypes`).
2. `Packages/KotodamaKit/Package.swift`: swift-tools-version 6.0; one library product per module target listed in Scope; dependency edges only as DESIGN §5.2 allows (for now: all modules may depend on `CoreTypes` only). Each target gets a placeholder `Placeholder.swift` (`public enum <Module>Placeholder {}`) and a trivial passing test.
3. `App/KotodamaApp.swift`: `MenuBarExtra("Kotodama", systemImage: "mic")` with menu items "About Kotodama" (opens standard about panel) and "Quit" (`NSApplication.terminate`). Must build and run as a menu-bar-only app (no Dock icon).
4. `.gitignore`: `*.xcodeproj`, `Frameworks/*.xcframework`, `.DS_Store`, `build/`, `DerivedData/`, `Packages/KotodamaKit/.build/`, `*.partial`.
5. `.swiftlint.yml`: default rules + `line_length: 140 warning`; placeholder section `custom_rules:` with a comment reserving `no_network_outside_modelcatalog` (implemented in issue 27).
6. `docs/BUILD.md`: prerequisites (Xcode ≥ current stable, `brew install xcodegen swiftlint swiftformat`), commands: `xcodegen generate`, `xcodebuild -project Kotodama.xcodeproj -scheme Kotodama build`, `swift test --package-path Packages/KotodamaKit`.
7. All UI strings added in this issue go through `Localizable.xcstrings` (source language `ja`) from the start (DESIGN §19); create the catalog with the two menu strings.

## Acceptance Criteria

- [ ] `xcodegen generate && xcodebuild … build` succeeds on a clean clone (arm64 Mac) with no committed `.xcodeproj`.
- [ ] `swift test --package-path Packages/KotodamaKit` passes (12 placeholder suites).
- [ ] Launching the app shows a menu-bar mic icon, no Dock icon; About and Quit work.
- [ ] `swiftlint` and `swiftformat --lint .` report zero violations.
- [ ] Bundle id, deployment target, arch, `LSUIElement`, mic usage description, Hardened Runtime setting verifiable in generated project (`xcodebuild -showBuildSettings` output pasted in PR).
- [ ] No file references outside the target-name/path contract above (later issues depend on it).

## Validation

Paste in the PR: clean-clone build log tail, `swift test` summary, screenshot of the menu-bar menu, `xcodebuild -showBuildSettings | grep -E 'PRODUCT_BUNDLE_IDENTIFIER|MACOSX_DEPLOYMENT_TARGET|ARCHS|ENABLE_HARDENED_RUNTIME'`.
